# NasPlayer：纯 ArkTS 原生鸿蒙 SMB3.1.1 视频播放器 — 实施计划

## Goal

在 `E:\code\NasPlayer\NasPlayer` 创建并实现 **HarmonyOS 6.0 原生手机 App**（API Level 由本机 SDK 自动检测），**全部代码使用 ArkTS 编写、符合官方语法（arkts-* 规则）、不引入任何 JS 依赖**：

1. 自研 **ArkTS SMB 协议栈**（支持最新 SMB 3.1.1 方言 + NTLMv2 + 签名），连接 NAS（可配置主机、端口、共享名、用户名、密码、域），浏览共享目录。
2. 在线播放 NAS 视频：**播放/暂停/继续**、进度条拖拽 seek、**倍速播放**。
3. **上下滑动切换**上/下一部视频；播放控件**点击唤出/隐藏 + 无操作自动隐藏**；**横屏沉浸式全屏**播放。
4. **海报墙网格**浏览（AVImageGenerator 缩略图，失败回退占位图）。

## Scope / Non-goals

**In scope**
- 项目脚手架（`deveco-create-project` 私有脚本）。
- ArkTS 自研 SMB2/3.1.1 客户端：NEGOTIATE（方言 0x0202/0x0210/0x0300/0x0302/0x0311）、SESSION_SETUP（NTLMv2 + SMB3.1.1 预认证 SHA-512 + MIC）、TREE_CONNECT、CREATE、QUERY_DIRECTORY、READ 范围读、CLOSE、LOGOFF；SMB 请求签名（HMAC-SHA256）。
- 本地 HTTP Range 流代理（AVPlayer 唯一网络播放通道）。
- 配置持久化、列表/海报墙浏览、播放器页（横屏、倍速、手势、控件显隐）。

**Non-goals（一期不做）**
- **SMB3 加密（AES-128-CCM）**：不协商 EncryptData（现代 NAS/Windows/Samba 默认允许不加密）。
- 共享自动枚举（SRVSVC）、NTLMv1/LM 旧协议回退。
- 字幕、音轨选择、投屏、断点续播记忆、多 NAS 配置。
- 转码（依赖系统解码能力；mkv/HEVC 部分封装不支持属正常限制）。
- **不引入任何 JS 库/Node shim**（用户明确要求纯 ArkTS）。

### 2) SMB 协议栈（纯 ArkTS，`entry/src/main/ets/smb/`）

> 实现前先加载 `arkts-grammar-standards` 技能并阅读其 `references/recipes-core.md`；每个 `.ets` 写完即自查 Top-5 陷阱（解构/未类型化字面量/原型/导出导入/kit 命名空间），全部文件必须过 `arkts_check`。

**`smb/SmbCrypto.ets`**
- `md4(data: Uint8Array): Uint8Array` — 纯 ArkTS 实现（标准 RFC 1320 算法：3 轮 48 步 + 4 个常量 + 小端填充；逐字节 Uint8Array 操作）。
- `hmacMd5(key: Uint8Array, data: Uint8Array): Promise<Uint8Array>`、`hmacSha256(...)`、`hmacSha512(...)` — 封装 `cryptoFramework.createMac('HMAC|MD5'|'HMAC|SHA256'|'HMAC|SHA512')` + `createCipher` 不需要；`sha512(data): Promise<Uint8Array>` — `createMd('SHA512')`。
- `randomBytes(n: number): Promise<Uint8Array>` — `cryptoFramework.createRandom()`。
- 所有方法显式 `Promise<T>` 返回类型标注；错误转 `BusinessError`。

**`smb/SmbPacket.ets`**
- SMB2 头常量（64B：ProtocolId `FE 53 4D 42`、StructureSize、Status、Command、Flags、MessageId、ProcessId、TreeId、SessionId、Signature@48）。
- `SmbMessage` 类：`serialize(): Uint8Array`（DataView 小端写入 + 动态长度字段）；`parseHeader/parseBody`。
- NBSS 帧封装：4B 前缀（0x00 + 3B 大端长度）。
- 各消息体构建/解析：NEGOTIATE（req/resp）、SESSION_SETUP（req/resp）、TREE_CONNECT、CREATE、QUERY_DIRECTORY（FileBothDirectoryInformation 解析：NextEntryOffset/FileAttributes/EndOfFile/FileName）、READ（req/resp）、CLOSE、LOGOFF。

**`smb/SmbSocket.ets`**
- 包装 `socket.constructTCPSocketInstance()`：`connect(host, port)`（Promise）、`write(data: Uint8Array)`（`send`）、`onMessage(cb)`（`on('message')`，ArrayBuffer→Uint8Array）、`onClose/onError`、`close()`；内部**粘包缓冲**：累积字节流，按 NBSS 帧长解析出完整 SMB2 消息队列；连接状态机（connecting/connected/closed）。

**`smb/Ntlm.ets`（NTLMv2，全 async）**
- `createType1(workstation: string, domain: string): Promise<Uint8Array>` — NEGOTIATE 标志 + 域/工作站 ANSI。
- `parseType2(buffer: Uint8Array): Promise<NtlmChallenge>` — 解析 8B server challenge（+可选 TargetInfo）。
- `createType3(username, workstation, domain, serverChallenge: Uint8Array, password: string): Promise<NtlmType3Result>` — 返回 `{ message: Uint8Array; sessionKey: Uint8Array }`：
  - NT hash = MD4(UTF-16LE(password))（纯 ArkTS md4）
  - NTLMv2 hash = HMAC-MD5(NT hash, UTF-16LE(user)+UTF-16LE(domain))
  - blob = `0x01010000` + 8B FILETIME + 8B 随机 + 空 TargetInfo
  - ntProofStr = HMAC-MD5(NTLMv2 hash, serverChallenge+blob)；response = ntProofStr+blob；LMv2 同源构造
  - sessionBaseKey = HMAC-MD5(NTLMv2 hash, ntProofStr)
  - Type3 消息按 [MS-NLMP] 组包（ANSI 域/用户 + 响应字段 + 大小端）

**`smb/SmbClient.ets`（协议状态机，核心）**
- 成员：socket、`messageId: number`、pending Map（`Record<number, (msg)=>void>` 或对象表）、`sessionId/treeId`、`dialectRevision/securityMode`、`sessionKey: Uint8Array | undefined`、`preauthNegotiateReq/Resp: Uint8Array`。
- `negotiate()`：请求方言 `[0x0202, 0x0210, 0x0300, 0x0302, 0x0311]`、SecurityMode=0x01（SIGNING_ENABLED）、ClientGuid 随机；记录原始请求字节；响应记录原始字节 + `dialectRevision/securityMode`（**dialect 由服务器选择，兼容降级**）。
- `sessionSetupStep1()`：SMB3.1.1 时填 `PreauthIntegrityHashValue = SHA512(negotiateReq || negotiateResp)`（64B）；`SessionId=0`；响应 STATUS_MORE_PROCESSING_REQUIRED → parseType2。
- `sessionSetupStep2()`：createType3 → 存 `sessionKey`；SMB3.1.1 填预认证哈希；dialect≥3.0 时在请求尾部追加 **MIC** = HMAC-SHA256(sessionKey, negotiateReq || step1响应 || step2请求原始字节)；捕获原始字节序列用于 MIC（先组包后算 MIC 再写入）。
- `treeConnect(share)`、`create(path)`（FILE_OPEN，返回 FileId）、`queryDirectory(fileId)`（FileBothDirectoryInformation 解析）、`read(fileId, offset: bigint, length): Promise<Uint8Array>`（每请求 ≤ 64KB 分块循环）、`close(fileId)`、`logoff()`。
- **请求签名**：sessionKey 建立后，每条请求 `Signature = HMAC-SHA256(sessionKey, 消息)`（Signature 字段先置 0，按 [MS-SMB2] 3.1.4.1）写入头偏移 48 并置 `Flags.SIGNED=0x08`；响应签名不校验（注释注明）。
- **并发复用**：pending 按 MessageId 关联响应，允许多个请求在途（播放器 seek 时范围读交错）。
- 所有错误映射为 `BusinessError`（`@kit.BasicServicesKit`）；提供 `debugLog`（hilog，`@kit.PerformanceAnalysisKit`）开关供联调抓包对比。

**`smb/SmbSession.ets`（高层 API，供 service 层调用）**
- `connect(config: SmbConfig): Promise<void>` — 完整握手（negotiate→session→treeConnect）+ 一次 `queryDirectory('')` 验证。
- `readdir(relPath: string): Promise<VideoEntry[]>`（目录/文件 + size）、`getSize(relPath): Promise<number>`、`readRange(relPath, offset: number, length: number): Promise<Uint8Array>`（open→read 循环→close，文件句柄短生命周期）、`disconnect(): void`。

### 3) ArkTS service 层（`entry/src/main/ets/service/`、`model/`）

- `model/VideoEntry.ets`：`interface VideoEntry { path: string; name: string; size: number; isDirectory: boolean }`；`model/SmbConfig.ets`：`interface SmbConfig { host: string; port: number; share: string; username: string; password: string; domain: string }`（显式 export/import）。
- `service/ConfigStore.ets`：`@ohos.data.preferences`（`getSync/putSync`）读写 SmbConfig。
- `service/SmbService.ets`（单例）：持有 `SmbSession`；`connect/readdir/getSize/readRange/disconnect` 透传；`StreamServer` 与播放页共用该会话（**同一 SMB 连接**，避免重复握手）。
- `service/StreamServer.ets`（单例）：
  - `socket.constructTCPSocketServerInstance()` bind `127.0.0.1` + 随机端口（20000–60000 冲突重试；`port: 0` 若 SDK 支持则优先）；`getUrl(path): string` → `http://127.0.0.1:port/stream?f=<encodeURIComponent(path)>`。
  - 每连接：解析 HTTP 请求行/头（支持 `Range: bytes=a-b`）→ `200 OK`（Content-Length、Accept-Ranges: bytes、Content-Type 按扩展名映射 mp4/mkv/avi/mov/ts/webm/wmv/flv/m4v）或 `206 Partial Content`（Content-Range）；body 256KB 分块经 `SmbService.readRange` 回读；连接关闭即中止并释放句柄；并发连接共享同一 SMB 会话（多请求在途复用）。
  - `start()/stop()` 幂等。

### 4) UI 层（`entry/src/main/ets/pages/`）

- **`Index.ets`（@Entry，配置页 + Navigation 容器）**
  - `Navigation(this.pathStack)` + NavDestination 承载 Browser/Player（子页面不进 `main_pages.json`）。
  - 表单：主机、端口（默认 445）、共享名、用户名、密码（`InputType.Password`）、域（默认 WORKGROUP）；「保存」「连接并浏览」；启动回填。
  - 连接：保存配置 → `SmbService.connect()` → 成功 `pushPathByName('Browser', ...)`；失败 toast（`this.getUIContext().getPromptAction().showToast`）。
- **`BrowserPage.ets`（NavDestination）**
  - **视图切换**：列表（List + LazyForEach IDataSource）与**海报墙网格**（Grid + LazyForEach GridItem，`columnsTemplate('1fr 1fr 1fr')`）；右上角切换按钮。
  - 海报墙：每项 = 缩略图 + 文件名；缩略图用 `media.createAVImageGenerator()`（`@kit.MediaKit`）+ `fetchFrameByTime`（t≈1s，数据源指向 `StreamServer.getUrl(path)`，`AVImageGenerator` 依赖 Range 服务）→ PixelMap → `Image`；**惰性加载**（仅可见项）、内存 LRU 缓存、失败/超时回退占位图标（内置图标 + 文件名）；generator 用完即释放。
  - 点目录推进（readdir），点视频 → 以**当前目录全部视频文件（按名排序）**为播放列表 `pushPathByName('Player', { files, index })`；返回按钮 + 系统返回（`onBackPressed` 优先弹路径栈）；断连提示重试。
- **`PlayerPage.ets`（NavDestination，`hideTitleBar(true)`）**
  - **横屏沉浸式**：`aboutToAppear` 后经 `this.getUIContext().getHostWindow()` 调 `setPreferredOrientation(Orientation.LANDSCAPE)` 与 `setWindowSystemBarEnable([])` 隐藏系统栏；离开页面（`aboutToDisappear`/返回）恢复 `PORTRAIT` + 恢复系统栏（**必须成对恢复**，异常路径也要保证）。
  - `XComponent`（surface + `XComponentController`）：`onReady` 取 `getXComponentSurfaceId()` → `media.createAVPlayer()` → `setVideoSurface` → `url = StreamServer.getUrl(file)` → `prepare()` → `play()`。
  - 事件：`stateChange`（loading/播放/暂停/完成/error+重试）、`timeUpdate/durationUpdate`（进度条 `Slider` → `seek`）。
  - **倍速**：按钮循环 `media.PlaybackSpeed.SPEED_FORWARD_0_75_X → 1_00_X → 1_25_X → 1_50_X → 2_00_X`（按 SDK 实际枚举/数值 API 适配），当前倍速显示在按钮上。
  - **控件显隐**：控制层（播放/暂停、倍速、上/下一部、标题、时间、进度条）默认显示；播放中 3 秒无操作自动隐藏；点击屏幕切换显隐；交互操作重置计时器。
  - **滑动切换**：根 `Stack` 挂 `SwipeGesture`（`SwipeDirection.Up` 下一部、`Down` 上一部）；`switchInProgress` 防抖；切换 = `player.reset()` → 新 URL → prepare → play；首尾越界 toast；播完显示「下一部」。
  - 生命周期：`aboutToDisappear` → `player.release()` + StreamServer.stop + 恢复竖屏/系统栏；`onPageHide` → `player.pause()`；`onPageShow` → 按需恢复。

## Risks And Compatibility

- **SMB3.1.1 协议正确性（最高）**：预认证哈希/签名/MIC/NTLMv2 组包严格依赖 [MS-SMB2]/[MS-NLMP]。缓解：模块化 + hilog 抓包调试 + Windows 共享先联调；SMB 2.1 降级路径保留（服务器不支持 3.x 时自动兼容）。
- **MD4 纯 ArkTS 实现正确性**：RFC 1320 标准算法，实现后与已知测试向量（如 `password` → `8846f7eaee8fb117ad06bdd830b7586c`）对照验证（可加临时调试断言）。
- **cryptoFramework 异步约束**：全部协议流程 async/await 化；TCPSocket 事件回调 → Promise 状态机衔接注意竞态（消息到达顺序与 pending 表）。
- **AVImageGenerator 依赖 HTTP Range 服务**：若对本地 HTTP 流取帧不稳定 → 海报墙回退占位图（网格功能不受影响）；如可取帧则惰性+缓存控制开销。
- **横屏/系统栏恢复**：onPageHide/aboutToDisappear 双路径都要恢复竖屏与系统栏，防状态泄漏。
- **AVPlayer 格式限制**：依赖系统解码器；mkv/HEVC 部分封装可能无法播放，UI 明确错误文案（非崩溃）。
- **性能**：范围读为网络往返，seek 大文件短暂缓冲；256KB chunk + 多请求在途复用可接受。
- **API 级别**：自动检测；SDK 不匹配时报错原样上报，不擅自降级。
