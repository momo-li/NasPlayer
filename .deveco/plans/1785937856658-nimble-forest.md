# NasPlayer 自动随机播放 + 视频库扫描

## Goal
1. 用户在某文件夹（共享根或任意子目录）点击「设为视频源并扫描」→ App 递归扫描该文件夹下所有视频，记录扫描列表（持久化）。
2. 冷启动 App：若开启自动播放且已有视频库 → 自动连接 NAS → 随机选一部直接播放；上下滑动切换视频；一部播完自动随机切下一部。
3. 自动播放可在设置中关闭（默认开启）；首页保留手动「随机播放」入口。

## Scope / Non-goals
- 包含：视频源设置、递归扫描与进度、库持久化（文件）、冷启动自动播放、播完随机下一部、开关。
- 不包含：缩略图库/海报墙扩展、多视频源管理（仅一个当前源）、在线搜索。
- 不包含：解决 QUERY_DIRECTORY 挂起的长期根因（仅作为前置条件验证其可用；若不可用，方案 B 见 Risks）。

## Current State And Constraints
- PlayerPage 已具备：横屏、倍速、控件显隐、进度条、**上下滑动切换（PanGesture，顺序 index）**、播放列表来自 `params.files`（VideoEntry[]）。
- BrowserPage 已具备：目录浏览（readdir）、当前目录视频收集后进入播放器。
- SmbSession/SmbClient：`readdir`（QUERY_DIRECTORY + 迭代）、`getSize`、`readRange`；StreamServer 提供 HTTP Range 播放。
- ConfigStore（preferences）：主机/凭据/共享列表/主机列表缓存已存在。
- **硬前置阻塞**：`QUERY_DIRECTORY` 在真机 NAS 上挂起（无响应），目录浏览当前不可用 → 递归扫描无法工作。已对照验证：smbprotocol（NEGOTIATE 带 preauth+cipher+compression+netname 共 4 个 context）可正常列目录；当前实现 NEGOTIATE 仅带 preauth context。Node 侧加 cipher context 后 NEGOTIATE 被 0xC000000D 拒（结构未与 smbprotocol 精确对齐），需按 smbprotocol 字节级结构修正。

## Design

### 1. 前置：修复 QUERY_DIRECTORY 挂起（执行第 1 步，硬依赖）
- 将 `SmbPacket.negotiateReq` 的 NEGOTIATE 调整为与 smbprotocol 逐字节对齐：
  - preauth context：`01 00 26 00` + 数据 38 字节（`00 00 00 00` + `01 00 20 00 01 00` + salt 28？—— 以 smbprotocol wire 实测为准：len=38、数据 38 字节）
  - cipher context：`02 00 0a 00` + `00 00 00 00` + `04 00 02 00 01 00`（cipher 列表 4/2/1）
  - compression context：`03 00 00 00`（len=0）
  - netname context：`05 00 1a 00` + `00 00 00 00` + host utf16（与 smbprotocol 实测 len=26 对齐）
  - `ctxCount=4`，每 context 后 8 字节对齐；`ctxOffset=64+36+dialects+pad`
- 真机验证：进入共享后 BrowserPage 能列出根目录内容（readdir 返回非空）。

### 2. 视频库服务（新 `service/VideoLibrary.ets`）
- 单例，持有：`source: {host, share, rootPath} | undefined`、`files: VideoEntry[]`、`scannedAt`、`scanning` 状态。
- `scanLibrary(host, share, rootPath, onProgress(done,total))`：
  - BFS 队列递归调用 `SmbService.readdir(relPath)`；跳过 `.`/`..`；深度上限 8；条目上限 5000（超限停止并提示）；跳过隐藏目录（名字以 `.` 开头）。
  - 收集 `MediaUtil.isVideo(name)` 的文件（沿用现有扩展名判断）。
  - 扫描结束后写入缓存文件（见下）并更新时间戳。
- `loadLibrary()`：启动时从缓存文件恢复。
- `randomIndex()`：`Math.floor(Math.random()*files.length)`（排除与当前相同项由调用方处理）。
- 持久化：**文件而非 preferences**（列表可能上千条）→ `getContext().filesDir + '/video_library.json'`，结构 `{host, share, rootPath, scannedAt, files:[{path,name,size}]}`；用 `fs` 写入（try/catch 容错）。

### 3. ConfigStore 扩展
- 新增 key：
  - `videoSource`：JSON `{host, share, rootPath}`（设置视频源时保存）
  - `autoPlayEnabled`：boolean，默认 true（开关切换时保存）
- 新增 `saveVideoSource/loadVideoSource/saveAutoPlay/loadAutoPlay`。

### 4. BrowserPage：设置视频源入口
- 顶部工具栏加「设为视频源」按钮（作用于 `currentPath`，根目录时 rootPath 为空串表示共享根）。
- 点击后：保存 videoSource（host 取 `SmbService.currentHost`，share 取 `SmbService.currentConfig.share`）→ 调用 `VideoLibrary.scanLibrary` → 弹进度（toast 或页面内进度条，`scanning` 状态）→ 完成后 toast「已收录 N 部视频」，并在工具栏显示「▶ 随机播放」入口（直接进 PlayerPage，files=库）。

### 5. PlayerPage：播完自动随机下一部
- `completed`/`endOfStream` 状态时：若 `files.length > 1` → 随机选一个与当前不同的 index → `playEntry`；否则停止显示「播放完成」。
- 随机逻辑放 VideoLibrary 或 PlayerPage 内联（`index = Math.floor(Math.random()*len); if (index===this.index) index=(index+1)%len`）。
- 自动播放进入时返回栈：Index 为根，退出自动播放回首页（现有 NavDestination 行为，无需改）。

### 6. Index：冷启动自动播放 + 开关 + 手动入口
- `aboutToAppear`（在 loadCachedHosts 后）：
  - 读 `autoPlayEnabled` 与 videoSource → 有源且开关开 → `VideoLibrary.loadLibrary()` → 库非空 → 自动执行：`SmbService.connectHost(保存凭据)` → 进度提示「正在连接…」→ `enterShare(share)` → 随机 index → push PlayerPage（files=库, index=随机）。
  - 失败（连接失败/库空/未配置）→ toast 原因，留在首页，不阻塞其他 UI。
- 首页新增一行状态/入口：
  - 「视频源：D\xxx（N 部）」文案 +「🎲 随机播放」按钮（手动触发上述自动流程）。
  - 「自动播放」Toggle（默认开）→ `ConfigStore.saveAutoPlay`。
- 连接过程复用现有 `doConnect` 的错误提示风格（toast 分类）。

## Risks And Compatibility
- **最大风险**：QUERY_DIRECTORY 挂起若无法按步骤 1 修复，自动扫描与自动播放全部不可用。备用方向（仅在前置失败时评估，不默认执行）：会话启用加密（impacket 加密会话可列目录）或 SMB 2.1 降级目录查询；需用户确认后另立计划。
- 大目录扫描耗时（深度/数量上限防卡顿）；扫描期间 UI 用进度提示，禁止重复触发。
- 冷启动自动播放需 1~3s 连接；失败路径必须静默回首页（不弹阻塞对话框）。
- preferences 仅存小配置；视频库用 filesDir 文件，避免大数据卡 preferences。
- 自动播放从根页 push PlayerPage：返回时回首页（现有行为，无额外改动）。

## Rollback
- 代码：`git checkout -- <改动文件>` 即可回退；新增 `VideoLibrary.ets` 删除即可。
- 配置：新增 key 均为独立项，不影响旧流程；关闭「自动播放」开关后行为与旧版一致（首页手动浏览）。
- 缓存文件：删除 `filesDir/video_library.json` 即清空视频库记录。
